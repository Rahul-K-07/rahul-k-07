## 🚀 Featured Projects

### 🌿 [NicheAtlas — Unified Plant Traits Dashboard](https://github.com/Rahul-K-07/Crop-Dashboard)

An interactive plant-traits exploration dashboard with a focus on organizing and visualizing plant characteristics.

- Built with **Flask, Python, Pandas, Scikit-learn, Plotly, and JavaScript**
- Organizes plant traits such as root type, growth form, leaf traits, reproductive traits, and stress adaptations
- Includes filtering, plant comparison, trait visualizations, clustering, and similarity exploration
- Uses **PCA and K-Means** to explore patterns in plant-trait data

### 🌾 AgroIntellect — AI-Driven Crop Intelligence

An agricultural decision-support project combining machine learning, weather information, and remote-sensing features.

- Developed a crop prediction workflow using **Random Forest**
- Explored model comparisons with XGBoost, CatBoost, LightGBM, and TabNet
- Integrated weather data and Google Earth Engine-derived vegetation and water indices
- Explored explainability with SHAP and district-level agricultural analysis

### 📚 Library Management System

A web-based library management project built around the **MERN stack**.

- Focus on core library workflows and role-based application structure
- Explored authentication, database integration, and deployment considerations
